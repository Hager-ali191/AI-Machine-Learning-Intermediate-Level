How vectorization avoided loops:
Vectorization means applying an operation to an entire column at once instead of one record at a time. np.where() flags every transaction in a single call, `df['amount'] * 0.01` scales the whole column through broadcasting, and groupby().agg() summarizes by region, all running in compiled C code over contiguous memory, which avoids the per-row Python overhead and temporary objects that were causing the timeouts and memory crashes in the old for-loop script.
